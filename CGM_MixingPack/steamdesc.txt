[h1]Biome Remix Pack[/h1]

This mod adds a bunch of vanilla biomes as biome remix options.
These Biome Remixes work the same as those added by dlcs, embedding themselves into asteroids with open remix slots during worldgen.
Combine it with [url=https://steamcommunity.com/sharedfiles/filedetails/?id=2947429297]CGM[/url] for more granular control of target asteroids.

[h1]Bug Reports & Local Download[/h1]

[h3]Mod is marked as "incompatible" / the game is stuck in an "update loop"?[/h3]
This means that the game failed to install the mod. This is usually caused by Ony Mod Manager breaking the download or OneDrive breaking the games' ability to install mods.
Follow [url=https://steamcommunity.com/sharedfiles/filedetails/?id=3522703974]this guide[/url] to fix the OneDrive issue and replace Ony Mod Manager with Mod Updater if not done already.

You can find also direct downloads for my mods [url=https://github.com/Sgt-Imalas/Sgt_Imalas-Oni-Mods/releases]here[/url] (please notify me if I forgot to release new versions).

Please post bug reports and issues on [url=https://github.com/Sgt-Imalas/Sgt_Imalas-Oni-Mods/issues] GitHub[/url] or on my [url=https://discord.gg/5n7peBCnWZ]Discord Server[/url]. 
[b]Always include the full player.log in a report: [/b] https://github.com/aki-art/ONI-Mods/wiki/How-to-send-a-log

[b]Make sure you do NOT have the mod "Debug Console" enabled as it breaks the game's logging and makes the log useless for fixing issues[/b]
